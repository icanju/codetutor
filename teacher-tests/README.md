# 교사용 오류 검증 파일

여기 있는 Python 파일은 튜터를 직접 시험하기 위한 별도 자료입니다. `curriculum.md`, Supabase 문제 데이터, AI 시스템 프롬프트에 넣지 않았고, 어떤 힌트가 나와야 하는지도 적지 않았습니다.

Render 앱에 로그인한 뒤 IDE의 `파일 열기`를 눌러 원하는 `.py` 파일을 선택하고 실행하세요. 각 단계는 직접 눌러 확인하면 됩니다. 파일을 고르는 것만으로는 Gemini에 전송되지 않으며, 3단계 AI 설명을 요청할 때 코드와 오류 내용이 Gemini API에 전달됩니다.

파일 내용은 교사가 확인할 때만 사용하세요. 학생 과제로 공개할 자료는 아닙니다.
